# Don Ventas — sitio público

Este repositorio (`donventas/landing`) es la fuente editable del sitio. El sistema
de marca vigente y las decisiones aprobadas gobiernan su expresión; Claude Design
es una referencia de interpretación, no una fuente superior al repositorio.

- Preservar cambios ajenos. Trabajar en una rama `codex/…` y PR desde `main`;
  nunca editar producción directamente. Esto actualiza la instrucción histórica
  de usar exclusivamente `dev` en `CLAUDE.md`.
- Publicar el preview para revisión. No fusionar ni desplegar a producción sin
  aprobación explícita del usuario para el release correspondiente.
- Antes de crear, reescribir o publicar un artículo, leer completo
  `blog/WORKFLOW-EDITORIAL.md`. Ejecutar sus compuertas proporcionalmente antes
  de presentar el preview, sin esperar a que Arturo las solicite.
- Recuperar el texto, decisiones y evidencia del artículo. No reabrir un relato
  aprobado por estética, keywords o supuesta optimización para IA. Distinguir
  experiencia declarada, fuente externa, ejemplo ilustrativo e hipótesis.
- No copiar contexto privado de clientes al repo público. Recuperar solo lo
  autorizado; abstraer preguntas y métodos sin exportar sus respuestas privadas.
- No modificar Portal, Runtime, AVOS o BSB como efecto secundario de este workflow.
- `node --test tests` y QA visual son verificaciones distintas; ninguna equivale
  a aceptación de Arturo, indexación, posicionamiento ni resultado comercial.
